STEP 01

On your TV

  1. Open Settings → System or Device Preferences → About.
  2. Select Android TV OS build or Build seven times.
  3. Go back to Developer options. Enable the debugging option supported by your TV.
  4. Keep the TV awake on the same trusted Wi-Fi or local network as your computer.
  5. Write down the TV model and the IP address and port it displays. If the TV shows a pairing code, note that code and its separate pairing port too.
Some TVs use USB debugging for network ADB; others show Network, ADB or Wireless debugging, and some require pairing first. Support and ports vary. A USB debugging switch alone does not guarantee Wi-Fi access. Never expose ADB through router port forwarding.
STEP 02

On your computer

  1. Download the official APK into a folder you can find.
  2. Open local Claude Code on this computer in that working folder. Use your local terminal or IDE with shell access.
  3. Click Copy installation prompt, paste it into the session, and provide the APK’s full file path, your TV model and its address when Claude asks.
  4. Let Claude verify the file, check your device and ask for installation approval.
Claude Code needs access to your computer’s terminal and local network. A cloud-only chat cannot reach your TV. This website never connects to your TV. Your Claude account and usage are separate from this free launcher, and Claude is not needed after installation. Prefer to do it yourself? Manual installation guide ↗ · Official Claude Code setup ↗
STEP 03

Follow along

  1. Approve “Allow USB debugging?” or the device’s pairing prompt on the TV when requested. Only approve your own computer.
  2. Confirm the exact TV and answer Claude’s questions about your favourite apps.
  3. Claude records the baseline, checks what can be backed up, installs the verified APK and tests the result. Default Home setup is a separate, device-specific approval.
  4. Keep the recovery instructions. After maintenance, turn debugging off on the TV.
No uninstall, factory reset or automatic package disabling is authorized by this prompt. Private app data may not be accessible for backup. Recovery is device-specific, not a guaranteed one-line restore.

Full install & recovery guide ↗
Prefer to install manually?

Use a trusted file manager/USB drive or authorized Android platform-tools. Verify the checksum first. Replace TV_SERIAL with the serial you confirmed with adb devices -l.

adb -s TV_SERIAL install -r {{FILENAME}}

Installing adds an app. It does not automatically make it your Home screen. Keep the stock launcher installed and follow only the procedure for your exact device.

A FEW THINGS TO KNOW

Straight answers.

Do I need Claude Code to use the launcher?

No. Claude Code is the guided installation option, running on your computer. You can also sideload manually. After installation, the core launcher needs no Claude account or running PC.

Will it work on every Android or Google TV?

No broad compatibility claim is made. One TCL G10 running Android 12 was tested as an update. A fresh install, another TV and its default-Home behavior remain unverified. Read the compatibility guide before proceeding.

Do the long fingerprints expose a secret?

No. A checksum and a public signing-certificate fingerprint are meant to be shared for verification. They do not let someone sign an update. Private signing keys and passwords must never be published.

Will this remove ads inside Netflix or other apps?

No. ZeroPulse changes the launcher interface. It does not bypass streaming subscriptions or change advertisements inside streaming apps.

Does the setup prompt debloat my TV automatically?

No. It installs the verified launcher with approvals. Default-Home changes are separate and depend on the exact TV. No general manufacturer-package disabling is authorized. The maintainer’s private debloat scripts are not included.

Can I go back to the stock home screen?

Follow the recovery plan for your device. Keep the stock launcher installed. Re-enable any launcher/setup components that you explicitly changed before switching back. App downgrades may require uninstalling and lose settings; the guided prompt does not authorize that.

Can I use JARVIS chat or voice today?

Public JARVIS pairing is unavailable until the compatible OpenPulse TV link is released. Local typed TV commands still work. Voice is not implemented in 2.1.
