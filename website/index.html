STEP 01 · TV SETUP & PERMISSIONS GUIDE

Prepare Developer Options & Unknown Apps

  1. Open Settings → System (or Device Preferences) → About on your Android TV or Google TV.
  2. Select Android TV OS build (or Build) seven times until “You are now a developer!” appears.
  3. Go back one screen to Developer options and turn on USB debugging or Wireless debugging (keep the TV on the same trusted Wi-Fi network and note its IP address and port, plus any pairing code).
  4. Open Settings → Apps → Security & restrictions → Unknown sources (or Special app access → Install unknown apps) and allow Downloader and ZeroPulse TV.
Support and menus vary slightly across Sony, TCL, Onn, and Chromecast Google TV models. A USB debugging toggle alone does not enable network ADB on every TV. Never expose ADB through router port forwarding.

STEP 03 · INSTALL OR UPDATE VIA WIRELESS ADB

Connect over port 5555 & update cleanly

  1. Download {{FILENAME}} and open Terminal or local Claude Code on your computer. Use your local Windows terminal or IDE. Give Claude the full Windows path to the APK.
  2. Connect over your local Wi-Fi using port 5555: adb connect <TV_IP>:5555 — then approve “Allow USB debugging?” on your TV.
  3. Run adb install -r {{FILENAME}} (never uninstall first so existing users keep their saved dock and settings intact).
  4. Enable ZPAPPS app installation permission over ADB: adb shell appops set tv.calmhome.launcher REQUEST_INSTALL_PACKAGES allow
  5. When finished, turn debugging off on the TV.
This website never connects to your TV. Your Claude account and Claude Code are not needed after installation. No uninstall, factory reset or automatic package disabling is authorized. Recovery is device-specific, not a guaranteed one-line restore.

A FEW THINGS TO KNOW

Straight answers.

How do I keep my saved dock when updating?

Always update in place using adb install -r {{FILENAME}} or install the new APK directly over the existing version via Downloader. Never uninstall first, or Android will erase your saved dock order and launcher settings.

Why does ZPAPPS ask for “Install unknown apps” permission?

The built-in ZPAPPS Toolbox and custom Downloader shortcode engine download companion TV app APKs locally and hand them to Android’s package installer. You can grant this in TV Settings or via adb shell appops set tv.calmhome.launcher REQUEST_INSTALL_PACKAGES allow.

Do the long fingerprints expose a secret?

No. A checksum and a public signing-certificate fingerprint are meant to be shared for verification. They do not let someone sign an update. Private signing keys and passwords must never be published.

Will this remove ads inside Netflix or other apps?

No. ZeroPulse changes the launcher interface. It does not bypass streaming subscriptions or change advertisements inside streaming apps.

Does the setup prompt debloat my TV automatically?

No. It installs the verified launcher with approvals. Default-Home changes are separate and depend on the exact TV. No general manufacturer-package disabling is authorized. The maintainer’s private debloat scripts are not included.

Can I go back to the stock home screen?

Follow the recovery plan for your device. Keep the stock launcher installed. Re-enable any launcher/setup components that you explicitly changed before switching back. App downgrades may require uninstalling and lose settings; the guided prompt does not authorize that.

Do I need Claude Code or a PC to install?

No. You can install straight on your TV using AFTVnews Downloader in Step 2, or use Wireless ADB (Step 3) on Windows, macOS, or Linux — either manually or with local Claude Code.
