# Graphite Liquid Glass

The supplied Download Center reference sets the layout. The secondary reference locates the Assistant shortcut. Both images are design references. Every title, input, button, icon, history row, progress indicator and focus target in the app is a native Android view or drawable.

## Surfaces and navigation

- The shared backdrop draws two static graphite curves with a silver edge. It is rasterized once and scaled to the screen, so a moving focus ring never regenerates the wallpaper.
- Glass surfaces use layered graphite fills with a diagonal specular rim. The palette ranges from #0B0E12 through #151A20, #252B32 and #40464D, with #F6F7F8 text, #BEC5CD secondary labels and authentic installed app artwork.
- The six destinations share a floating capsule. A silver raised pill marks the active section, a brighter outline marks focus, and a separate live clock can include the date. Content stays inside a five-percent margin. Focus normally takes 150 ms, and reduced-motion settings suppress scaling and transitions.
- The downloaded or photographed content never supplies UI chrome. Home can show the owner's chosen photo with its credit; Settings → Appearance switches between the graphite and photo backdrops. The Wallpapers screen retains preview, rotation and attribution.
- Home shows favorite apps, a recent shelf derived exclusively from successful launches through ZeroPulse, and local navigation. Apps filters only installed launchable packages, with search, favorites and Android-declared media/game categories.
- Downloads places direct entry before its six monochrome category cards, followed by live transfers, installed-app artwork and a bottom action dock. A row with unknown total bytes uses an indeterminate indicator. Empty sections report what the TV actually contains.

## Verification

Inspect the real 1080p and 4K rasters as well as accessibility bounds. A reported 4K physical display can still host a 1080p Android UI surface. Compare focus/clipping, active tab contrast, text overflow, keyboard dismissal, Back restoration and frame times on real hardware. The QA acceptance document separates measured observations from unsupported hardware paths.
